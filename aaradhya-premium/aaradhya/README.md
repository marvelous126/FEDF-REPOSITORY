# Aaradhya — Premium Frontend

A cinematic, premium spiritual-travel frontend for the Aaradhya concept.

## Files
- `index.html` — complete page structure
- `styles.css` — responsive visual system and animations
- `script.js` — search, filters, favourites, booking modal, navigation and story slider

## Run
Open `index.html` directly in a modern browser. No build step is required.

## Notes
The demo uses remote Unsplash images and Google Fonts. Replace those URLs with licensed/local assets for production. Booking is UI-only until a backend/payment/database is connected.
